The initial trajectory includes that distance plus nonnegative launch traversal loss; it does not use `Driver.Gap` release times, sort launch scores or add grid gaps afterward. Detailed Starts, overtaking/defending (the supported Racecraft projection), Error Control and setup-adjusted traction/acceleration Deployment weighted by circuit demands affect bounded launch loss. Driver/event keyed SHA256 opening samples have a separate `opening-keyed-v1` identity. Aggregate layouts use an explicit 5000-metre reference length for grid conversion; segmented layouts use their authored physical lengths. Imagery supplies no geometry.

The engine advances its existing event loop to the common timestamp of the leader's lap-one crossing, including every simultaneous boundary event. Trailing fractional progress, recorded timing traces, tyre wear/age, segment trajectories and encounters remain live. Opening does not increment the strategy phase index. The first normal five-lap Race Phase therefore ends at leader lap six. A configured one-lap simulation finishes during the opening and requires no first decision. There are no incidents, contact damage, retirements, Safety Cars or player launch choices in this slice.

Q3's final-grid branch creates the opening within the existing durable commit. Frozen source/content/model/setup inputs, ordered grid, full explicit configuration/tuning, preparation identity, seed and opening outcome hash are saved with the session. Recovery reruns and verifies the opening before accepted plans on the same reconstructed engine; ordinary `PhaseResult` is never imported as state. Browser replay and strategy replay understand optional versioned opening inputs; older rolling records remain valid. Failed writes discard speculative engines; confirmed post-commit retries retain the original receipt and opening. Opening events advance the event cursor before normal highlights.

The server's eight-second presentation policy, generation guard, pause/remaining-duration handling, host Continue and scheduled delivery govern handoff. Opponent plans, timeout plans, assistance observations and the first decision deadline are initialized from the post-opening engine only after presentation completes. The first editable window is phase zero. Normal, skipped and reduced-motion clients show the same classification; their local playback changes no simulation state. The public opening projection contains allowlisted identities, grid positions and legal gains/losses, without seeds or hidden launch inputs.
