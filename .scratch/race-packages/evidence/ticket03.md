## Refinement

Refinement requires an exact completed specialised source version; baseline and pending work are rejected. It uses the same one opportunity and ledger, with a ten-credit base price and the existing bounded efficiency discount/floor. The frozen quote includes source data, operation, target-version reservation, personnel, cost and policy:

- **Strengthen:** strongest positive modifier +1, declining to +0.5 from source version 3, capped at +6.
- **Reduce compromise:** largest negative modifier moves one point toward zero.
- **Broaden usefulness:** add one point against the largest weakness, capped at +2 there, while surrendering 0.5 of the strongest modifier. Existing all-circuit availability stays unchanged; no circuit unlock is invented.

Partial and compromised refinement use half the stated change; breakthrough doubles it within bounds; compromised adds a bounded Reliability -1. Every result creates a new immutable version/history. Pending versions reserve their number, so a delayed v2 and independent next-opportunity v3 can coexist. Existing selected/frozen v1 is unchanged. Strict campaign integrity validates the prior completed own source, exact debit, unique version reservations, saved probabilities, concrete outcomes and effective library snapshots.
